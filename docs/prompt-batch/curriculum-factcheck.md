# Curriculum guide fact-check (AUD-04, AUD-15, AUD-16)

**Scope.** Every factual claim in `CURRICULUM_PROMPT` and `SOURCE_LIBRARY` in `server.js`, plus the claims the audit transcripts show the tutor inventing around them. Checked on 2026-10-18 and 2026-10-19 with web search and, where the page could be fetched, the primary source itself.

**This is a draft for human review.** The founder or a teacher should still open the sources below before merging. That matters most for the rows marked **Medium** or **Check**.

**How to read the table**
- **Old → New** quotes the guide text, shortened where it is long. "(added)" means the guide had no fact there, so the tutor made one up; the new text gives it a vetted one instead.
- **Confidence**
  - **High:** the primary source, or two independent reputable sources, say the same thing.
  - **Medium:** only secondary coverage, or the wording is a judgement call.
  - **Check:** a human should look before merging.
- **"(model)"** marks a false claim the audit caught the tutor making that the guide did not contain word for word. It is fixed by the new FACT RULES ("use only this guide's numbers") plus a vetted replacement fact.
