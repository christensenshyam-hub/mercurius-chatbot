Here's something that might surprise you: AI image generators don't work like collages.

They don't search a database and stitch real photos together. They start from pure random noise — like TV static — and gradually sculpt it into an image, guided by your text prompt.

That process is called a **diffusion model**.

[KEY]A diffusion model starts from random noise and "denoises" it step by step until a coherent image emerges that matches a text prompt.[/KEY]

[EX]Think of it like a sculptor starting with a shapeless block and chipping away until a face appears — except the "block" is random pixel values, and the "chisel" is a neural network trained to reverse noise. Tools like Midjourney, Stable Diffusion, and ChatGPT's image generator all work this way.[/EX]

This is fundamentally different from older approaches (like GANs, which pitted two networks against each other). Diffusion models are why today's AI images look so strikingly realistic.

Exactly right — noise in, image out. That's the core insight.

Now let's talk about what this same idea does to *sound*.

**Voice cloning** works on a similar "learn the pattern, generate new output" principle — but instead of pixels, it's modeling the unique characteristics of someone's voice.

Modern systems need surprisingly little audio to work with. Microsoft's VALL-E research model claimed it could clone a voice from just 3 seconds of sample audio.

[KEY]Voice cloning captures the acoustic "fingerprint" of a real person's voice and uses it to generate new speech they never actually said.[/KEY]

[EX]Text-to-video works the same way, extended into time. Tools like OpenAI's Sora and Google's Veo generate video frame by frame from a text prompt — again, starting from noise, not from real footage. No real clip is being edited. Every pixel is synthesized.[/EX]

The key thread across images, voice, and video: these systems **generate** new content from scratch. They don't retrieve or remix real media. That's what makes them so powerful — and so hard to detect.
