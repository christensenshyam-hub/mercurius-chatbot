Exactly right — that's **tokenization**.

Her words get broken into tokens (pieces of words, whole words, or punctuation), and each token gets converted into a number. That's the only thing the model can actually work with — numbers.

Now, once those numbers are in, the model uses something called the attention mechanism to figure out how words relate to each other. That's how it knows "internet" in Priya's question is about technology, not something else.

Then — and this is the key part — it doesn't *retrieve* an answer. It predicts the next token, then the next, then the next, building the response one piece at a time based on patterns from training.
