```text
Exactly right — numbers that *stand in for* the word-chunks, yes!

And here's where it gets interesting: once your prompt is a sequence of numbers, the model needs to figure out how those numbers *relate* to each other.

That's where the **attention mechanism** comes in.

Attention is how the model connects words that belong together, even when they're far apart in a sentence.

[EX]"The trophy didn't fit in the suitcase because it was too big." — What does "it" refer to? The trophy. Attention is what lets the model link "it" back to "trophy" across several words.[/EX]

This is also how "bank" gets sorted out. The model looks at every other token in your sentence and asks: which ones tell me what "bank" means here? If "river" is nearby, attention pulls that connection.

If "loan" is nearby, it pulls that one instead.

[KEY]Attention lets the model weigh which tokens matter most for understanding each other token — context is built from relationships, not definitions.[/KEY]

[Q]
What problem does the attention mechanism solve?
A) It translates tokens back into readable words
B) It connects tokens to each other so context shapes meaning
C) It checks the internet for the most likely answer
ANS: B
[/Q]
```

```text
You've got it exactly right — that's precisely how attention works!

Now here's the part that might blow your mind a little: after all that context-building, what does the model actually *do* with it?

It predicts the next token. That's it. That's the whole trick.

The model looks at your entire prompt — all those tokens, all those relationships — and asks one question: **what token is most likely to come next?**

Then it picks one, adds it to the sequence, and asks the same question again. And again. Until the response is done.

[EX]Finish this: "The cat sat on the ___" — almost everyone thinks "mat." An LLM assigns very high probability to "mat" or "floor," and very low probability to "democracy" or "seventeen." It picks from that probability distribution.[/EX]

This means the model isn't retrieving a stored answer from somewhere. It's *generating* one token at a time, each one based on everything before it.

[KEY]An LLM generates responses by repeatedly predicting the single most probable next token — it's not looking anything up.[/KEY]

[Q]
When an LLM generates a response, what is it actually doing?
A) Searching a database for the best matching answer
B) Picking the next token based on probability, one at a time
C) Translating your question into the language it was trained on
ANS: B
[/Q]
```
