# Mercurius AI — App Store listing pack (2.3.0)

Everything to paste into **App Store Connect → Mercurius AI → 2.3.0**. Every
field below is copy-paste ready; the character counts were measured on the
exact text inside the code fences (not on the headings). Re-count if you edit.

Before submitting, rehearse the build on a device with
[`REVIEW_REHEARSAL.md`](REVIEW_REHEARSAL.md).

Product facts this pack is written against (do not advertise anything else):

- Store name **Mercurius AI**, Education, iPhone + iPad (universal), iOS 17+, free, no
  accounts, no ads, no tracking. Age rating **13+** (forced via the
  minimum-age option).
- Three modes — **Socratic** (default), **Discussion**, **Debate**. There is no
  "Direct" mode any more; do not mention one anywhere.
- A learning path of **8 units / 35 lessons**; lessons stream in beats with
  tappable **KEY IDEA / EXAMPLE / CHECK** cards; the server marks a lesson
  complete when the student demonstrates the objective; unit checks; streaks
  and optional daily reminders (local notifications).
- Photos can be attached to a message and are sent through our server to
  Anthropic's Claude with the message. **All replies are generated by Claude.**
- Built by the **Mayo AI Literacy Club**, a student club.

Wording to avoid everywhere (store, site, reviewer notes): "revolutionizes",
"replaces tutors", "guarantees learning", "eliminates cheating", "the only app
you need", "confidence signal", "stays on your device". Prefer specific,
checkable claims: "guides with questions", "built around verification and
reflection", "responses are generated by Claude".

## 2. Age rating (the questionnaire answers)

App Store Connect's questionnaire produces 4+, 9+, 13+, 16+ or 18+. Answer it
truthfully, then use the **minimum age** option to set **13+** regardless of
what the answers alone compute. Mercurius asks the student's age on first
launch and blocks under-13s, so the store rating and the in-app gate agree.

| Question | Answer | Why |
|---|---|---|
| Cartoon or fantasy violence | None | — |
| Realistic violence | None | — |
| Prolonged graphic or sadistic realistic violence | None | — |
| Profanity or crude humor | None | Tutor is prompted to stay in register. |
| Mature or suggestive themes | Infrequent/Mild | Lessons discuss deepfakes, scams and consent, algorithmic bias in criminal justice, and autonomous weapons — as topics, never depicted. |
| Horror or fear themes | None | — |
| Medical or treatment information | Infrequent/Mild | One lesson on AI in healthcare; the AI-limits screen shows the 988 crisis line. |
| Alcohol, tobacco or drug use or references | None | — |
| Sexual content or nudity | None | — |
| Graphic sexual content and nudity | None | — |
| Simulated gambling | No | — |
| Real gambling / contests | No | — |
| Unrestricted web access | No | The app has no browser. Links in replies open in Safari and only https links are allowed. Remote images never load. |
| Messaging and chat / user-generated content | No user-to-user messaging | The only chat is with the AI tutor; there is no way for users to see each other's content. Users can report any reply from inside the app. |
| Advertising | None | — |
| Loot boxes / in-app purchases | None | Free, no IAP. |
| Parental controls / age assurance | Age check on first launch | Under-13 is blocked and nothing is stored. There is no parental-control feature to declare. |
| Minimum age (override) | **13+** | Force it here. |

Do **not** opt into the Kids category. It is the wrong fit for an AI chat app
and brings COPPA-style constraints the product does not meet.

## 3. App Privacy (the nutrition label)

Must match `ios/Mercurius/Resources/PrivacyInfo.xcprivacy`. If the manifest
and this label ever disagree, review will bounce the build — update both
together.

**Do you collect data from this app?** Yes.

| Data type (ASC category → type) | Collected | Linked to the user's identity | Used for tracking | Purpose |
|---|---|---|---|---|
| Identifiers → **User ID** (the anonymous session id) | Yes | **No** | **No** | App Functionality |
| User Content → **Other User Content** (chat messages, attached-photo captions, reported content) | Yes | **No** | **No** | App Functionality |
| User Content → **Photos or Videos** (photos the student attaches to a message) | Yes | **No** | **No** | App Functionality |
| Everything else (contact info, health, financial, location, contacts, browsing/search history, usage data, diagnostics, purchases, sensitive info) | No | — | — | — |

- **Tracking:** No. There are no advertising or analytics SDKs, no IDFA use and
  no tracking domains in the privacy manifest.
- The label describes what the app sends to **our own server**. The server
  forwards messages and photos to Anthropic to generate replies; the privacy
  policy says so. Nothing is collected before the student agrees on the
  first-launch disclosure screen.
- The session id is a random string in the Keychain and is not linked to a
  name, email, phone number or Apple ID — none of those are ever asked for.

**Notes** (paste into *App Review Information → Notes*):

```
Mercurius AI is an AI-literacy tutor for students 13 and up, built by the Mayo AI Literacy Club (a student club). No account or login exists: the app creates an anonymous session id on the device.

WHERE REPLIES COME FROM
Every tutor reply is generated by Claude, Anthropic's AI model. The app talks only to our own server at https://mercurius-chatbot-production.up.railway.app, which calls Anthropic and streams the reply back. The server needs no login. A network connection is required.

FIRST LAUNCH (what you will see, in order)
1. Age check. Enter an age. Under 13 is blocked — the app shows a short message and stores nothing; relaunching shows the age check again. Enter 13 or older to continue.
2. Disclosure. A screen explains that messages and any attached photos are sent through our server to Anthropic's Claude, with links to the privacy policy and terms. The student must tap Agree to continue ("Not now" pauses at this screen and nothing is sent).
3. AI limits. A screen explains that the tutor can be wrong, is not a person, and is not for emergencies; it shows the 988 Suicide & Crisis Lifeline.
4. "Your path". Lesson 1 is offered, with an optional daily-reminder toggle (local notifications only; the prompt appears only if the toggle is turned on).
Tap Start on Lesson 1: the lesson streams in short beats with tappable KEY IDEA / EXAMPLE / CHECK cards.

MODES
Socratic (default, guides with questions), Discussion (reflect and get a scored response) and Debate (argue a side against the tutor, with sources). Switch with the pills at the top of the chat.

PHOTOS
Tap the photo button left of the message field, pick a photo, add a message and send. The photo goes through our server to Claude with the message. Photo-library access is read-only and only for the photo chosen.

REPORTING A REPLY (Guideline 1.2)
Long-press any tutor reply → Report → choose a reason (wrong / harmful / off topic / other). Reports go to our server for review; we act on them. There is no user-to-user content anywhere in the app.

DATA DELETION
Settings → "Delete my data & start over" erases the session's data on our server and issues a new anonymous id. Settings also shows the full session id, "Privacy choices" (withdraw consent, which returns to the first-launch flow), Help & FAQ, and Contact support.

USAGE LIMITS
Each session has a daily usage allowance, and we can pause the tutor server-side for maintenance. If you hit either, the app shows a plain message such as "You've used today's lesson turns. Mercurius will be ready again tomorrow." or "Mercurius is temporarily paused — please try again soon." The limits are generous and you are unlikely to see them; if you do, please contact us and we will lift them for your session.

Links inside replies open only https URLs in Safari; remote images never load inside the app.

Support: support@trymercurius.com
```
