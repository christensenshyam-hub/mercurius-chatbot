# Mercurius iOS App

Native Swift/SwiftUI iOS app for the Mayo AI Literacy Club's Mercurius tutor. Replaces the React Native app in `/mobile`.

## Architecture

- `Mercurius/` — the thin `@main` app target. Builds `AppEnvironment`, installs the notification delegate, and hands off to `RootView`.
- `MercuriusWidgets/` — the widget extension that hosts the learning Live Activity.
- `Packages/DesignSystem/` — colors, typography, spacing, reusable UI primitives, the Merc mascot.
- `Packages/NetworkingKit/` — single `APIClient`, SSE streaming, progress sync, typed errors, session identity (Keychain-backed).
- `Packages/PersistenceKit/` — the SwiftData chat store and small UserDefaults-backed stores (streak, reminders, last activity, review prompt).
- `Packages/ChatFeature/`, `Packages/CurriculumFeature/`, `Packages/SettingsFeature/` — the feature screens. They may depend on the infra packages above but not on each other (Curriculum → Settings is the one exception); `Packages/ArchitectureTests/` enforces this.
- `Packages/EngagementFeature/` — streaks, achievements, reminders and notification handling.
- `Packages/MercuriusActivity/` — the Live Activity, shared by the app and the widget extension.
- `Packages/AppFeature/` — composition root (`AppEnvironment`) plus the views that wire the features together (launch, onboarding, Home, the tab shell).

The project file (`Mercurius.xcodeproj`) is **generated by `xcodegen` from `project.yml`** and is not checked in. Edit `project.yml`, then run `xcodegen` to regenerate.

## Local setup

```bash
# one-time
brew install xcodegen

# every time the project layout changes:
cd ios
xcodegen
open Mercurius.xcodeproj
```

## Running

- **Simulator:** ⌘R in Xcode.
- **Tests (all):** ⌘U in Xcode.
- **Tests (package only):** `swift test` inside `Packages/`.

## Bundle identifier

Currently `com.mayoailiteracy.mercurius.native` to avoid conflict with the React Native app's `com.mayoailiteracy.mercurius`. Swap to `com.mayoailiteracy.mercurius` when the React Native app is retired.

## Backend

Points to `https://mercurius-chatbot-production.up.railway.app` (production). For local dev, use `APIEnvironment.local` which targets `http://localhost:3000`.

## What ships

- Chat with Merc in three modes (Socratic / Debate / Discussion), with photo attachments and response reporting
- An 8-unit curriculum on a learning path, with unit tests and progress synced to the server
- Streaks, weekly and daily reminders, and a learning Live Activity
- First-run age gate, disclosure and limits; Settings with data deletion and privacy choices
- SPM package tests, snapshot tests and XCUITests (see `.github/workflows/ios.yml`)
- On the App Store; the submission checklist lives in `docs/APP_STORE.md`

## Standards

Every change should:

- Feel native (SwiftUI first, UIKit only when clearly better)
- Handle loading / empty / error / retry / offline states
- Support VoiceOver, Dynamic Type, Reduce Motion, dark mode
- Avoid main-thread blocking (use `async/await` with proper actors)
- Come with unit and/or UI tests
- Not log sensitive user content
- Not hard-code credentials
